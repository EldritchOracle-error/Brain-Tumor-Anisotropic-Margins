# Brain-Tumor-Anisotropic-Margins
Official B.Tech dissertation repository for 'A Tensor-Constrained Energy Minimization Model for Predicting Microscopic Brain Tumor Margin Expansion'. Implements DTI-guided Fast Marching Eikonal PDEs and Volume-Matched Calibration across N=25 UPENN-GBM patient cases for optimized, personalized radiotherapy target volumes.
